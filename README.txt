IMPORTANT
Ce système d'administration utilise localStorage. Il fonctionne sans serveur et évite de modifier le code,
mais les données sont enregistrées uniquement dans le navigateur utilisé. Pour une administration réelle,
accessible depuis plusieurs appareils et sécurisée, il faut connecter le site à une base de données et à un serveur.

GOOGLE REVIEWS
La page avis attend un point serveur :
GET /api/google-reviews
La clé Google doit rester sur le serveur. Ne jamais l'insérer directement dans le JavaScript public.

CHAT

PUBLICATION
